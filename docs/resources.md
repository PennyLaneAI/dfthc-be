## Reason codes

The codes of a row are the causes with a nonzero contribution to its delta, with that contribution (against dfthcbe; against the paper); the contributions sum to the delta exactly, and two different causes may cancel (`dfthc.costs_reference.delta_causes`).

| Code | Meaning |
| --- | --- |
| `flat-r` | r is carried through the inner swap; heterogeneous targets are deferred |
| `no-prune` | no aligned-block pruning of unary-iteration boundaries: dfthcbe stops once on each aligned block of a dead interval, and a walk over a sub-range [lo, hi) can be truncated only that way (costs_reference.iteration_counts) |
| `exact-iter` | exact unary iteration: out-of-range addresses raise no flag, which costs at most one Toffoli per address bit at each range end; dfthcbe's truncated iteration is cheaper (costs_reference.iteration_counts) |
| `iter-const` | truncated iteration over L leaves costs L + c - 2 Toffolis with c controls; the paper counts L, one per leaf |
| `prefix-stops` | dfthcbe's walks over the tail rows [RC, X_o) (the tail load and the angle erase's tail fix-up) stop once on each aligned block of the dead SF prefix [0, RC), s(RC) stops; the paper's (B41, and B50's fix-up N) count their N leaves alone (costs_reference.iteration_causes) |
| `onehot-pad` | the fixup one-hot is padded to a power of two |
| `adder-const` | SemiAdder constants differ from Qualtran's |
| `mux` | spin-multiplexer construction |
| `attrib` | the paper attributes the cost to a different step |
| `junk-qubits` | junk persists until the erase |
| `rz-addsub` | each Givens R_z is Qualtran's ControlledAddOrSubtract, b_rot - 1 Toffolis, as in dfthcbe; the paper counts b_rot |
